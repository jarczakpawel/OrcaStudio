OrcaStudio - macOS first launch help

Use these steps only if OrcaStudio does not open normally.

  1. Drag OrcaStudio.app to the Applications folder.
  2. Try to open OrcaStudio normally from Applications.
  3. If macOS blocks the app, Control-click OrcaStudio.app, choose Open, and confirm Open again.
  4. If that option is not available, open System Settings > Privacy & Security, scroll to the Security section, and click Open Anyway.

No Terminal commands are normally required. This approval should only be needed for the first launch.

If OrcaStudio still has problems

Old application data or files left by an earlier build may cause problems. Quit OrcaStudio completely, then clear its local data and try again.

  1. Open Finder.
  2. From the menu bar, choose Go > Go to Folder..., or press Shift-Command-G.
  3. Paste this path exactly, including the ~ at the beginning:

~/Library/Application Support/BambuStudio_OrcaSlicer

  1. Move the contents of that folder to the Trash, or rename the whole folder as a temporary backup.
  2. Start OrcaStudio again.

This resets OrcaStudio's local settings, login data, cached plug-ins and local runtime files. You may need to sign in again and allow OrcaStudio to reinstall its runtime.
